# Android Control

USB로 연결한 안드로이드 폰의 화면을 PC에서 보고, 마우스와 키보드로 조작하는 파이썬 프로그램입니다.

다른 PC로 옮길 때는 [인수인계.md](인수인계.md)를 먼저 보세요. KTX 333 매진 감시(`watch_ktx333.py`) 설치·실행·무선 ADB 제한이 정리되어 있습니다.

## 준비

1. 폰에서 **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호**를 7번 눌러 개발자 모드를 켭니다.
2. **설정 → 개발자 옵션 → USB 디버깅**을 켭니다.
3. USB 케이블로 PC에 연결하고, 폰에 뜨는 **USB 디버깅을 허용하시겠습니까?**에서 허용을 누릅니다.
4. `adb`와 파이썬 패키지를 설치합니다.

```powershell
winget install Google.PlatformTools
pip install -r requirements.txt
```

`winget` 설치 후에는 PATH가 갱신되도록 터미널을 새로 열어야 합니다.

## 실행

```powershell
python android_control.py
```

연결 점검용 명령도 있습니다.

```powershell
python android_control.py --list       # 연결된 기기 목록
python android_control.py --selftest   # GUI 없이 화면 수신만 확인
```

주요 옵션입니다.

| 옵션 | 설명 |
| --- | --- |
| `--backend auto\|scrcpy\|screencap` | 화면 수신 방식 (기본 `auto`) |
| `--serial <시리얼>` | 기기가 여러 대일 때 대상 지정 |
| `--fps <숫자>` | 목표 FPS (기본 30) |
| `--max-size <픽셀>` | scrcpy 방식의 긴 변 최대 크기 (기본 1080) |
| `--height <픽셀>` | 창 초기 높이 (기본 880) |

## 조작 방법

| 입력 | 동작 |
| --- | --- |
| 좌클릭 | 탭 |
| 좌클릭 길게 (0.45초 이상) | 롱프레스 |
| 좌클릭 드래그 | 스와이프 |
| 마우스 휠 | 스크롤 |
| 우클릭 | 뒤로 가기 |
| 키보드 입력 | 폰으로 전달 (방향키, Enter, Backspace 포함) |
| 아래쪽 입력창 + 전송 | 문자열 한 번에 입력 |
| 상단 버튼 | 뒤로 / 홈 / 최근 앱 / 전원 / 깨우기 / 음량 / 화면 저장 |

저장한 화면은 `screenshots/` 폴더에 PNG로 들어갑니다.

## 화면 수신 방식 두 가지

기본값 `auto`는 scrcpy를 먼저 시도하고, 실패하면 screencap으로 넘어갑니다.

**scrcpy** 방식은 폰에 scrcpy 서버를 올려 H.264 영상을 받습니다. 화면이 바뀌는 순간에만
프레임이 오기 때문에 정지 화면에서는 프레임 수가 적게 표시되지만, 실제 조작할 때는 즉시 반응합니다.
`py-scrcpy-sdk` 패키지가 필요하고, 한글 입력도 클립보드를 통해 처리됩니다.

**screencap** 방식은 `adb screencap`을 반복 호출합니다. 추가 패키지 없이 동작하고 원본 해상도를
그대로 받지만, 매번 화면 전체를 전송하므로 느립니다. Galaxy A15(1080x2340) USB 연결에서 측정한
결과는 아래와 같습니다.

| 방식 | 프레임 획득 시간 | 초당 프레임 |
| --- | --- | --- |
| screencap (PNG 압축) | 781 ms | 1.3 |
| screencap (무압축 RGBA, 10.1 MB) | 1674 ms | 0.6 |

터치 명령은 `adb shell`을 계속 띄워둔 채 전송하므로 어느 방식이든 한 번에 약 2 ms가 걸립니다.

## 알아둘 점

- **한글 입력**: scrcpy 방식에서는 클립보드 붙여넣기로 처리됩니다. screencap 방식의
  `adb shell input text`는 ASCII만 지원하므로 한글을 보낼 수 없습니다.
- **보안 화면**: 은행 앱이나 DRM 영상처럼 캡처가 차단된 화면은 검게 보일 수 있습니다.
- 화면 회전은 자동으로 따라갑니다. 폰을 돌리면 창 안의 이미지 비율도 함께 바뀝니다.
- USB 케이블을 뽑으면 상태줄에 오류가 표시되고, 다시 연결하면 알아서 복구됩니다.
